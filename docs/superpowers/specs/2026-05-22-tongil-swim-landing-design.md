# 제로벨 7시 강습 · 통일로 원정수영 랜딩페이지 — 설계 문서

- 작성일: 2026-05-22
- 행사일: 2026-06-19(금), 통일워터파크 (오전 9시 개장 ~ 오후 6시 폐장)
- 목적: 제로벨 7시 강습반 단톡방에 공유 → 통일워터파크 단체 원정수영 참가자 모집 → 오픈채팅방 입장 유도

## 1. 개요

제로벨 실내수영장 7시 강습반 멤버들이 **6월 19일(금) 통일워터파크로 단체 원정수영**을 가는 행사 안내 및 참가자 모집용 단일 페이지. "다 같이 신나게 놀다 오자~" 하는 캐주얼·신나는 톤. 단톡방에 링크를 뿌리고, 참여 의사가 있는 사람은 **오픈채팅방으로 입장**하도록 유도하는 것이 1차 목표(전환).

## 2. 기술 스택 / 형태

- 단일 파일 `index.html`
- Tailwind CSS v4 **CDN** 사용 (빌드 단계 없음)
- 한글 폰트: Pretendard (CDN)
- **모바일 전용에 가까운 모바일 우선 설계** — 열람의 99%가 폰(단톡방 공유). 모바일이 1순위, 데스크탑은 중앙 정렬 컨테이너로 부수 대응.
- 워터/풀 느낌의 시원한 블루 팔레트 + 이모지 포인트
- 오픈채팅 링크는 `OPENCHAT_URL` 플레이스홀더로 작성 → 나중에 실제 URL로 한 줄 교체
- 단톡방 공유 미리보기용 Open Graph 메타태그(og:title, og:description, og:image 등) 포함

## 3-1. 모바일 최적화 요구사항 (최우선)

- `<meta name="viewport" content="width=device-width, initial-scale=1">` 필수
- 단일 컬럼 레이아웃, **가로 스크롤 절대 없음** (overflow-x 차단)
- 본문 기본 글자 크기 16px 이상, 줄간격 넉넉히 (작은 화면 가독성)
- 모든 버튼·링크 **탭 영역 최소 44×44px** (손가락 터치 기준)
- 하단 고정 CTA 바는 `position: sticky/fixed` + safe-area-inset(노치 대응) 패딩
- 섹션 간 충분한 여백, 카드형 블록으로 스크롤 시 정보 구분 명확
- 이미지/아이콘은 이모지·인라인 SVG 위주로 가볍게 → 모바일 데이터·로딩 부담 최소화
- Tailwind 기본(모바일 퍼스트) 클래스를 베이스로, `sm:`/`md:` 이상에서만 데스크탑 보정
- 세로로 길어지는 페이지이므로 섹션 점프용 상단 요약/앵커는 선택적으로 고려
